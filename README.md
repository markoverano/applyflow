# ApplyFlow

A lightweight, privacy-first job application tracker that runs entirely in your browser. No accounts, no servers, no data collection.

**Live:** [applyflow.pages.dev](https://applyflow.pages.dev)

## Features

- **Kanban board** — track applications across To Do, In Progress, Interview, Waiting, Offered, and Rejected columns
- **Drag & drop** — reorder and move cards between columns
- **Priority levels** — flag jobs as high, medium, or low priority
- **Job details** — store company, description, apply date, interview date, and a link to the posting
- **CSV export** — download your data anytime
- **Dark mode** — remembered across sessions
- **100% local** — all data lives in your browser's localStorage; nothing is ever sent to a server

## Tech Stack

- [React](https://react.dev)
- [Vite](https://vitejs.dev)
- [lz-string](https://github.com/pieroxy/lz-string) — localStorage compression

## Privacy

Your data never leaves your browser. See the in-app Privacy Policy for full details.
